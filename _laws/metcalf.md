title: Metcalf's Law
law: The value of a network is proportional to the square of the number of connected users of the system.
law-author: Robert Metcalfe
law-url: https://en.wikipedia.org/wiki/Metcalfe%27s_law
law-year: 1980
---

Named after Robert Metcalfe, the co-inventor of Ethernet and founder of 3Com, this law holds that the value of a network grows quadratically with the number of users. Each new user can connect with every existing user, so the number of possible connections grows as the square of the number of participants, even though the cost of adding that user grows only linearly. This helps explain the runaway success of networked products like the telephone, email, social media, and marketplaces: at some point the value of joining exceeds the cost, and the network begins to grow on its own. In software, Metcalf's Law is why platforms that foster network effects tend to dominate their markets, and why a developer or product team should weigh both the raw feature set and the size of the user base when evaluating a platform. As with other laws in this catalog, it is a useful rule of thumb rather than a precise physical law, and it has been subject to criticism over the years - for example, it treats all connections as equally valuable, which is rarely true in practice.
